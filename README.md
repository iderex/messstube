# messstube

Proprietary instrument binaries obstruct analysis and archiving while the instruments stay in service for decades. The general problem is being addressed - pynxtools, Profex, pyElli, and a Pistoia Alliance scoping effort since March 2026 - and this board says so rather than claiming the whole field. It takes the remainder those projects do not reach: Hall measurement rigs, profilometers, vacuum and sputter controllers, oscilloscope raw formats. Each reader is verified against real files from a real instrument rather than against a vendor specification.

Planning happens on the issue tracker first. Every decision that shapes
the architecture is written down there with its reasons before the code
that depends on it exists.
